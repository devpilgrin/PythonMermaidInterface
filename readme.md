# 🚀 Mermaid Studio — Визуальный редактор диаграмм Mermaid

**Python Mermaid Interface** — это инструмент с графическим интерфейсом для создания и редактирования диаграмм Mermaid. Идеально подходит для:
- Быстрого прототипирования
- Обучения синтаксису Mermaid
- Создания технической документации
- Визуализации архитектурных решений

## 🌟 Основные возможности

| Функция                  | Описание                                                                 |
|--------------------------|-------------------------------------------------------------------------|
| 🖥️ Веб-интерфейс          | Дружелюбный интерфейс на Gradio                                         |
| 📝 Подсветка синтаксиса   | Автоматическая подсветка кода Mermaid                                   |
| 🔄 Мгновенный рендеринг   | Мгновенное обновление диаграммы при изменении кода                     |
| 📸 Выбор формата          | Экспорт в SVG (вектор) и PNG (растровая графика)                        |
| 🧩 Система плагинов       | Расширяемые шаблоны диаграмм через плагины                             |
| 🚨 Обработка ошибок       | Подсказки при ошибках в синтаксисе Mermaid                             |
| 📂 Автоматическое сохранение | Результаты сохраняются в папку `output/`                              |

## 📲 Установка

### Требования:
- Python 3.8+
- Node.js 16+
- Chrome/Chromium (для PNG)

```bash
# 1. Клонируем репозиторий
git clone https://github.com/yourname/mermaid-studio.git
cd mermaid-studio

# 2. Устанавливаем зависимости Python
pip install -r requirements.txt

# 3. Устанавливаем mermaid-cli (глобально)
npm install -g @mermaid-js/mermaid-cli
```

## 🚀 Запуск

```bash
# Запуск приложения
python app.py

# Откройте в браузере:
# http://localhost:7860
```

## 🛠️ Использование

### Интерфейс
![Интерфейс Mermaid Studio](https://example.com/screenshot.png)

1. **Панель редактирования** — введите код Mermaid слева
2. **Выбор формата** — переключение между SVG и PNG
3. **Панель плагинов** — быстрая вставка шаблонов
4. **Результат** — отображение диаграммы справа

### Пример кода
```
graph TD
    A[Start] --> B{Decision}
    B -->|Yes| C[OK]
    B -->|No| D[End]
    C --> E[Process]
    E --> F((Result))
```

## 📦 Плагины

### Создание плагина
1. Создайте файл в `plugins/` (например `my_plugin.py`)
2. Добавьте содержимое:
```python
button_text = "Моя диаграмма"
insert_code = """sequenceDiagram
    participant User
    participant System
    User->>System: Запрос
    System-->>User: Ответ"""
```
3. Перезапустите приложение

## ⚠️ Известные ограничения

| Проблема                 | Решение                                  |
|--------------------------|------------------------------------------|
| Ошибки рендера PNG       | Убедитесь что Chrome установлен          |
| Медленная генерация       | Увеличьте таймаут в настройках           |
| Проблемы с кириллицей     | Добавьте `charset=utf-8` в начало кода   |
